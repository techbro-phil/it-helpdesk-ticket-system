# IT Helpdesk Ticket System

## Project Goal

A full stack IT Helpdesk Ticket Management System built using:

- React
- Node.js
- Express
- PostgreSQL

## Features

- Create tickets
- Update tickets
- Assign priorities
- Manage statuses
- Add technician notes
- Dashboard analytics

## Technologies Used

Frontend:
- React

Backend:
- Node.js
- Express

Database:
- PostgreSQL

Tools:
- Git
- GitHub
- VS Code
